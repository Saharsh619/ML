# Project 01: House Price Prediction

## 1. Problem Statement

A real estate company wants to develop a Machine Learning model that can predict house prices based on the size of a house.

Currently, the company estimates house prices manually, which can be time-consuming and inconsistent.

The objective is to develop a Linear Regression model that learns the relationship between house size and house price and predicts prices for new houses.

## 2. Objective

- Understand how Linear Regression works in practice.
- Explore and visualize the dataset.
- Train a Linear Regression model.
- Predict house prices using house size.
- Evaluate the performance of the model.

## 3. Dataset

We will initially use a small sample dataset created manually.

| Feature | Description |
|---|---|
| House Size | Size of the house in square feet |
| House Price | Price of the house in lakh rupees |
